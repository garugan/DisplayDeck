# DisplayDeck v0.1.0

DisplayDeck初回リリース。

## Features

- Windowsディスプレイの列挙
- 現在のディスプレイモード取得
- 診断情報表示
- Diagnostic JSON出力
- Read-only safety mode

## Limitations

v0.1.0ではディスプレイ設定の変更機能は提供していません。

Display modeの変更、Restore、WAL、Crash Recovery、Watchdogなどはv0.2以降で実装予定です。

検証済み範囲は記録済みWindows 10 Home 10.0.19045 x64 / NVIDIA GeForce RTX 4070 / driver 32.0.16.1088のexact cellです。Windows 11や他の構成での動作は未検証です。

この文書はRelease Notes原稿です。最終RCの証跡とGate C判定を確認後、release/v0.1.0/RELEASE_NOTES.mdへ収録します。
